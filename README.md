# Tetris Game

브라우저에서 바로 실행할 수 있는 전통적인 웹 테트리스 게임입니다. HTML, CSS, JavaScript만으로 구성되어 있으며 별도의 빌드 과정 없이 실행됩니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열면 게임을 시작할 수 있습니다.

```bash
open index.html
```

로컬 서버로 실행하고 싶다면 다음 명령을 사용할 수 있습니다.

```bash
python3 -m http.server 5173
```

이후 브라우저에서 `http://127.0.0.1:5173`에 접속합니다.

## 크롬 확장 프로그램으로 실행

이 저장소는 Manifest V3 크롬 확장 프로그램으로도 바로 로드할 수 있습니다. 별도의 빌드 과정은 없습니다.

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 프로젝트 폴더를 선택합니다.
5. 툴바의 `Classic Tetris` 아이콘을 눌러 별도 게임 창을 실행합니다.

확장 프로그램은 `popup.html`을 별도 Chrome popup 창으로 열기 때문에 다른 곳을 클릭해도 게임 창이 자동으로 닫히지 않습니다. 게임 창은 현재 Chrome 창 가운데에 기본 표시되고, 크기가 바뀌면 원래 게임 창 크기로 되돌립니다. 게임 창이 이미 열려 있을 때 툴바 아이콘을 다시 누르면 새 창을 만들지 않고 기존 게임 창을 앞으로 가져옵니다. 일반 브라우저 실행은 기존처럼 `index.html`을 사용합니다.

## 주요 기능

- 10 x 20 클래식 테트리스 보드
- 7-bag 방식의 블록 생성
- 다음 블록 미리보기
- 블록 보관 기능
- 점수, 최고 점수, 제거한 라인 수, 레벨 표시
- 최고 점수 브라우저 저장
- 기본 모드와 40라인 스프린트 모드 선택
- 40라인 스프린트 타이머, 남은 줄 수, 최단 기록 저장
- 레벨에 따라 빨라지는 낙하 속도
- 레벨에 따라 짧아지는 락 딜레이
- 블록이 바닥이나 아래 블록에 닿은 뒤 잠깐 동안 좌우 이동 및 회전 가능
- 착지 후 좌우 이동/회전 시 제한 횟수 안에서 고정 타이머 초기화
- 착지 위치 미리보기 옵션
- 효과음 옵션
- 모드, 착지 위치, 효과음 설정 브라우저 저장
- 일시정지 및 새 게임
- 키보드와 모바일 터치 조작 지원
- 반응형 레이아웃

## 조작법

| 입력 | 동작 |
| --- | --- |
| `←` | 왼쪽 이동 |
| `→` | 오른쪽 이동 |
| `↓` | 소프트 드롭 |
| `Space` | 하드 드롭 |
| `↑` | 반시계 방향 회전 |
| `X` | 시계 방향 회전 |
| `Z` | 반시계 방향 회전 |
| `C` | 블록 보관 |
| `P` 또는 `Esc` | 일시정지 / 계속 |

모바일 화면에서는 보드 아래의 터치 버튼으로 이동, 회전, 하드 드롭을 사용할 수 있습니다.

## 착지 위치 미리보기

착지 위치 미리보기는 기본적으로 꺼져 있습니다. 오른쪽 설정 패널의 `착지 위치` 토글을 켜면 현재 블록이 떨어질 위치를 반투명 블록으로 확인할 수 있습니다.

## 효과음

효과음은 기본적으로 켜져 있습니다. 오른쪽 설정 패널의 `효과음` 토글로 끄거나 다시 켤 수 있습니다. 이동, 회전, 소프트 드롭, 하드 드롭, 보관, 블록 고정, 라인 제거, 레벨 상승, 게임오버에 짧은 사운드 효과가 재생됩니다.

## 40라인 스프린트

설정 패널의 `모드`에서 `40라인`을 선택하면 40줄을 최대한 빠르게 지우는 스프린트 모드로 플레이할 수 있습니다. 스프린트 모드에서는 시간, 최단 기록, 남은 줄 수가 표시되며, 40줄을 모두 지우면 완주 시간이 브라우저에 저장됩니다.

## 점수 규칙

| 제거 라인 수 | 기본 점수 |
| --- | ---: |
| 1줄 | 100 |
| 2줄 | 300 |
| 3줄 | 500 |
| 4줄 | 800 |

라인 제거 점수는 현재 레벨을 곱해서 계산됩니다. 소프트 드롭은 한 칸당 1점, 하드 드롭은 한 칸당 2점을 추가합니다.

## 파일 구조

```text
.
├── index.html   # 게임 화면 구조
├── popup.html   # 크롬 확장 팝업 화면 구조
├── popup.js     # 확장 팝업 전용 도움말 동작
├── manifest.json # 크롬 확장 프로그램 설정
├── background.js # 확장 툴바 클릭 시 게임 창 열기
├── icons/       # 확장 프로그램 아이콘
├── styles.css   # 반응형 UI와 게임 패널 스타일
├── script.js    # 테트리스 게임 로직
└── README.md
```

## 구현 메모

- 게임 보드는 `canvas`로 렌더링합니다.
- 블록 생성은 7개 블록을 한 번씩 섞어 사용하는 7-bag 방식을 사용합니다.
- 최고 점수는 `localStorage`에 저장됩니다.
- 40라인 스프린트 최단 기록과 설정은 `localStorage`에 저장됩니다.
- 효과음은 별도 오디오 파일 없이 Web Audio API로 생성합니다.
- 하드 드롭은 즉시 고정되고, 일반 낙하로 착지한 블록은 레벨 기반 락 딜레이 후 고정됩니다.
- 착지한 블록이 좌우 이동이나 회전에 성공하면 블록 하나당 제한 횟수 안에서 락 딜레이가 다시 주어집니다.
